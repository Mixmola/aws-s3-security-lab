# AWS S3 Security Lab

## Project Overview

This is a hands-on AWS cloud security project focused on securing Amazon Simple Storage Service (Amazon S3) and implementing the principle of least privilege using AWS Identity and Access Management (IAM).

The project was created as part of my journey into cloud security, where I am developing practical skills by working with AWS services, configuring security controls, and testing access permissions.

## Project Objectives

- Secure an S3 bucket against public access.
- Configure server-side encryption.
- Enable S3 bucket versioning.
- Create and apply a custom IAM policy.
- Implement least-privilege access control.
- Test allowed and denied permissions using the IAM Policy Simulator.

## AWS Services Used

- Amazon S3
- AWS Identity and Access Management (IAM)
- IAM Policy Simulator
